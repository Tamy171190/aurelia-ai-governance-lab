# Project 04 - AI Control Framework

Translate AI Governance requirements into practical controls, evidence and testing across Aurelia's four operating jurisdictions.

## Control structure

**Requirement -> Applicability -> Risk -> Control Objective -> Control Activity -> Owner -> Frequency -> Evidence -> Test Procedure -> Finding**

## Multi-Jurisdiction Control Logic

Every control should identify:

- EU applicability and requirement theme
- UK applicability and requirement theme
- Singapore applicability and requirement theme
- UAE applicability and requirement theme
- ISO/IEC 42001 alignment
- NIST AI RMF function(s)
- Harmonised Aurelia control
- Jurisdiction-specific enhancement, if needed
- Control ceiling rationale

Where requirements overlap, the control is designed to the **highest applicable control requirement** where practical. A jurisdiction-specific enhancement is retained when a single harmonised control is insufficient.

## Control Testing

Testing should distinguish:

- Design effectiveness
- Implementation evidence
- Operating effectiveness
- Jurisdictional applicability
- Exceptions and legal-review dependencies

The project demonstrates how traditional assurance thinking can be applied to a multi-jurisdiction AI management system.
