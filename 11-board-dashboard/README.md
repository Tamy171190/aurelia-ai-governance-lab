# Project 11 — Board AI Governance Dashboard

Translate the AI inventory, risk, control and evidence information into concise Board and senior-management reporting.

## Core metrics

- AI systems by governance tier
- AI systems by jurisdiction
- Systems with unresolved applicability assessments
- High-governance systems
- Open high and critical risks
- Third-party AI dependencies
- Evidence completeness
- Control effectiveness
- Overdue remediation
- AI incidents
- Model or system changes
- Jurisdiction-specific control enhancements
- Control ceiling exceptions

## Board view

The dashboard should answer four questions:

1. **What AI do we have?**
2. **Where are the material risks and regulatory dependencies?**
3. **Are the controls working and is evidence available?**
4. **What requires management or Board attention?**

The dashboard should not imply that every AI system is subject to every jurisdictional framework. Applicability uncertainty and legal-review dependencies should be visible as governance indicators.
